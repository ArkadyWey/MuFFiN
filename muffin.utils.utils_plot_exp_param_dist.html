get_bin_edge_limits(min_val, max_val, num_bins)

Get bin edge limits so that we can define bins in next function.

Parameters:

  • min_val (-) – Min value that the distribution can achieve. For example, in the case of the depositiion parameter distriburion, this is zero.

  • max_val (-) – Max value the histogram can achieve. For example, in the case of the deposition parameter distribution, this is the mean of the undferlying conductance distribution.

Returns:

  • left_bin_edge (float) –

    • Left side of first bin. Use zero minus half the width of a bin, so that

    first bin is centred about zero.

  • right_bin_edge (float) –

    • Right edge of last bin. We use the mean of the conductance distribution plus

    half the width, so that the last bin is centred about the mean, since we know that is the maximal value that the histogram can achieve.
