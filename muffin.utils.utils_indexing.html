muffin.utils.utils_indexing.convert_indx_cell_to_grid_edge(i, j, r0, r1, i_c, j_c, num_nodes, num_rows)

Convert the cell index of an edge, which is a six-tuple (i,j,r0,r1,i_c,j_c), to the grid index of an edge, which is a pair (ii,jj).

Parameters:

  • i (-) – Index of node within the cell.

  • r0 (-) – Horizontal position of the cell that contains node j, relative to the cell that contains node i.

  • r1 (-) – Vertical position of the cell that contains the node j, relative to the cell that contains node i.

  • i_c (-) – Row that the cell that contains node i is in. Rows are indexed from 0 upwards. Row 0 is the bottom row in the grid.

  • j_c (-) – Column that the cell that containas node i is in. Colums are indexed from 0 upwards. Column 0 is on the left.

  • num_nodes (-) – Number of nodes in each cell.

  • num_rows (-) – Number of rows of cells in the grid.

Returns:

  • - ii (int) – A grid index description of the cell index (i,i_c,j_c), which is a number between 0 and num_nodes*num_rows*num_cols-1 (inclusive, since num_nodes*num_rows*num_cols is the number of nodes in the network).

  • - jj (int) – A grid index description of the cell index (j,i_c+r1,j_c+r0), which is the cell index of node j.

Reshape an edge quantity with grid indexing into the same edge quantity with cell indexing. For example, cond_2 back to cond_6 after the problem has been solved.

Parameters:

  • a_2 (-) – The same quantity defined on edges, indexed with grid indexing. That is, the quantity a on edge (ii,jj). We understand where this edge is by converting this grid descroption back to a cell description.

  • num_nodes (-) – The number of nodes in a cell.

  • num_rows (-) – The number of rows of cells in the network (not including external cells).

  • num_cols (-) – The number of columns of cells in the network (not including external cells).

Returns:

- a_6 – A quantity defined on edges, indexed with cell indexing. a_6[i,j,r0,r1,i_c,j_c] is the quantity a defined on the edge between the node i in cell i_c,j_c, and the node j located in the cell at r0,r1 relative to the cell containing i (i.e. node j in cell i_c+r1,j_c+r0). This includes edges to external nodes.

Return type:

numpy.ndarray

muffin.utils.utils_indexing.reshape_2_to_6_internal_edges(a_2, internal_edges, num_nodes, num_refs, num_rows, num_cols)

Reshape an edge quantity with grid indexing into the same edge quantity with cell indexing. For example, cond_2 back to cond_6 after the problem has been solved.

Parameters:

  • a_2 (-) – The same quantity defined on edges, indexed with grid indexing. That is, the quantity a on edge (ii,jj). We understand where this edge is by converting this grid descroption back to a cell description. This does not include edges to nodes that are in cells outside the network.

  • num_nodes (-) – Number of nodes in each cell.

  • num_refs (-) – Number of references.

  • num_rows (-) – Number of rows of cells in the network (does not include external cells).

  • num_cols (-) – Number of cols of cells in the network (does not include external cells).

Returns:

- a_6 – A quantity defined on edges, indexed with cell indexing. a_6[i,j,r0,r1,i_c,j_c] is the quantity a defined on the edge between the node i in cell i_c,j_c, and the node j located in the cell at r0,r1 relative to the cell containing i (i.e. node j in cell i_c+r1,j_c+r0).
